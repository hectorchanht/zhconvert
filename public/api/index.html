唔止係逐字轉換，而係成份文件轉換：格式、結構、排版原封不動，淨係轉應該轉嘅文字。兩個接入方式：MCP server 而家即用；hosted REST API 開發中，開放 waitlist 登記。

MCP Server — 而家即用

zhconvert-mcp 係俾 Claude 同其他 AI 工具直接用嘅 MCP server：喺對話入面即刻做簡繁轉換，用齊 14 個 OpenCC configs（含香港／台灣地區詞彙），本地行、唔經第三方 server。

安裝／行起（install & run）：

npx zhconvert-mcp

加落 Claude 嘅 MCP 設定（claude_desktop_config.json / .mcp.json）：

{
  "mcpServers": {
    "zhconvert": {
      "command": "npx",
      "args": ["-y", "zhconvert-mcp"]
    }
  }
}

套件頁：npmjs.com/package/zhconvert-mcp

Hosted REST API 做啲乜

  • 文件級轉換，保留格式 — EPUB 電子書成本轉、字幕（SRT / VTT / LRC / ASS）只轉對白唔掂時間軸、JSON 只轉字串值唔郁結構。EPUB, subtitles & JSON converted in place — structure untouched.
  • 14 個 OpenCC configs — s2t、s2tw、s2hk、s2twp、s2hkp、t2s 等齊全，連香港／台灣地區詞彙都分得開。Full OpenCC config set, incl. Hong Kong & Taiwan vocabularies.
  • 食舊編碼 — GBK / Big5 編碼嘅舊檔案直接入，唔會出亂碼。GBK & Big5 legacy encodings handled.
  • 私隱承諾 — 轉換過程唔保留你嘅文字內容。Your text is never retained.
  • 網頁版永遠免費 — API 係俾需要批量／自動化嘅團隊用；個人用網頁版轉換器一直免費、唔使註冊。
